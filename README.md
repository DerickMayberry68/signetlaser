# Signet Laser

Proposal, storefront mockup, and branding assets for the Signet Laser client preview.

## Artifacts

- `mockups/signet-laser-storefront.html` — interactive storefront, catalogue, personalization, custom work, and Admin Portal mockup.
- `proposal/signet-laser-proposal.html` — proposal for separate delivery by email.
- `output/pdf/signet-laser-proposal.pdf` — print-ready proposal with the matching hero image, for email delivery.
- `mockups/assets/` — placeholder product photography, recreated logo, and media source notes.
- Root SVG and image files — source branding artwork.
- `mockups/signet-laser-storefront-before-photos.html` — earlier design retained for reference.

Serve the `mockups` directory with a local static web server and open `/signet-laser-storefront.html` to preview. No build step is required.

The Admin Portal is intentionally included for client review. Product images and sample content are placeholders. The hero uses remote OMTech reference footage and requires an internet connection; the customer will supply a replacement video before public launch. Media details are recorded in `mockups/assets/README.md`.

This repository does not configure or trigger a deployment. The proposal remains separate from the storefront.
